# 鞋图四视图下载器 v1.2.1

Chrome / Chromium Manifest V3 扩展。将网页鞋图拖入 4 个位置，按鞋款、角度、序号和日期命名，并把高清原图直接写入指定文件夹。

命名示例：

- `D3119CM6-外侧-1-20260828.jpg`
- `D3119CM6-外侧-2-20260828.jpg`
- `D3119CM6-外侧-3-20260828.webp`
- `D3119CM6-外侧-4-20260828.jpg`

## v1.2.1 修正

- 四宫格预览禁止把 `currentUrl` / `bestUrl` 赋给 `<img>`，拖入阶段不会为了预览再次请求网页图片。
- 页面 Canvas 可读时，直接把页面已经显示的图片生成约 240px 本地 WebP 预览。
- Windows Chrome 如果在 `DataTransfer.files` 中提供已拖图片文件，只读取该文件生成本地预览；最终保存继续使用页面识别到的高清 URL。
- Canvas 受跨域限制时，尝试截取当前活动标签页已经显示的区域并裁切为本地预览。
- 上述本地预览方式都失败时，格子显示“未生成本地预览 / 原图地址已记录”，不会发起额外图片请求。
- 读取旧版队列时会清理 HTTP / HTTPS 形式的旧 `previewUrl`，防止升级后旧数据触发远程加载。
- content script 增加扩展上下文存活检查和同步异常捕获，减少开发者模式重载扩展后出现 `Extension context invalidated`。
- 开发者模式重新加载扩展后，已经打开的网页需要刷新一次，让该页面加载新版 content script。

## 功能

- Chrome 侧边栏界面。
- 统一拖放区，自动填入下一个空位。
- 4 个指定格子，可以直接拖到 1 / 2 / 3 / 4。
- 格子之间拖动交换顺序。
- 网页图片右键加入下一个空位或指定位置。
- 鞋款 `xxx` 与角度 `y` 自定义输入。
- 常用角度标签可以添加、删除。
- 日期格式 `YYYYMMDD`。
- 文件名实时预览。
- 从 `currentSrc`、`srcset`、懒加载属性、高清图属性、图片链接等位置记录高分辨率候选。
- 拖拽阶段只处理本地预览，点击保存后才获取最终高清原图。
- 重复图片提示。
- 根据最终图片响应类型识别 JPG、PNG、WEBP、AVIF 等扩展名。
- 指定文件夹保存，目录句柄记录在扩展 IndexedDB 中。

## 安装或升级

1. 解压发布 ZIP。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `shoe-view-downloader` 目录。
5. 已安装旧版时，可以覆盖原目录后点击“重新加载”。
6. 扩展重新加载后，把已经打开的商品页刷新一次，再开始拖图测试。

Edge Chromium 可以在 `edge://extensions/` 中按同样方式加载。

## 使用

1. 选择保存文件夹。
2. 填写鞋款与角度。
3. 从网页把图片拖入大拖放区或指定格子。
4. 四格只展示本地预览；高清候选 URL 同时被记录。
5. 调整顺序后点击“保存图片”，此时才并行获取高清原图并写入目标目录。

## 权限说明

- `sidePanel`：显示侧边栏。
- `storage`：保存队列、标签、设置和临时状态。
- `contextMenus`：提供网页图片右键快捷入口。
- `http://*/*` / `https://*/*`：读取网页图片元数据、获取最终原图，并允许扩展对匹配的活动标签页执行可见区域截图。

扩展没有远程脚本，也没有图片上传逻辑。

## 已知边界

- Canvas / WebGL 绘制内容缺少真实图片 URL 时，无法保证取得原始图片文件。
- 图片位于 iframe 内时，截图裁切坐标可能无法可靠换算；格子可能只显示“未生成本地预览”，高清地址仍会保留供保存阶段使用。
- 带复杂登录鉴权或一次性签名的高清地址可能失效。
- Blob 图片依赖原标签页临时转换，拖入后建议及时保存。
- 个别网站会拦截浏览器原生拖拽，此时可以使用图片右键菜单加入队列。
