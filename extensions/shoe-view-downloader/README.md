# 鞋图四视图下载器 v1.2.2

## v1.2.2 更新

- 拖入网页图片时，优先通过 Chrome DevTools Protocol 的 `Page.getResourceTree` + `Page.getResourceContent` 直接读取当前标签页已经加载的图片资源。
- CDP 取得的原资源只在内存中用于读取真实尺寸并生成约 240px 的本地预览；队列仍只持久化小预览，不把数 MB 原图写进 `chrome.storage.local`。
- 点击保存时，如果所选高清 URL 仍存在于来源标签页资源树中，直接再次读取已有资源并写入文件；资源不存在时才回退到正常网络获取。
- CDP 读取采用串行队列，每次读取结束都会在 `finally` 中 detach，避免四张并行保存时重复 attach 同一标签页。
- 图片右键入口打开 Side Panel 时改为 `windowId` 级别，避免把侧栏打开状态绑定到单独标签页。
- CDP 失败时继续保留 DataTransfer File、Canvas、可见标签页截图等原有回退。


Chrome / Chromium Manifest V3 扩展。把网页鞋图拖入 4 个位置后，按鞋款、角度、序号和日期命名，并把高清原图直接写入用户指定的文件夹。

命名示例：

- `D3119CM6-外侧-1-20260828.jpg`
- `D3119CM6-外侧-2-20260828.jpg`
- `D3119CM6-外侧-3-20260828.webp`
- `D3119CM6-外侧-4-20260828.jpg`

## v1.2.1 修正

- 四宫格预览彻底禁止把 `currentUrl` / `bestUrl` 赋给 `<img>`，拖入阶段不会为了预览重新下载网页图片。
- 页面 Canvas 可读时继续直接生成本地 240px WebP 预览。
- Windows Chrome 若在 `DataTransfer.files` 中提供已拖图片文件，只读取它生成本地预览，最终保存仍使用页面识别到的高清 URL。
- Canvas 受跨域限制时继续尝试当前标签页截图裁切；缺少原 tabId 时会回退到当前活动标签页。
- 如果所有无网络预览方式都失败，格子显示“未生成本地预览 / 原图地址已记录”，不会再发起额外图片请求。
- 读取旧版队列时会清除 HTTP/HTTPS 远程 `previewUrl`，避免升级后旧数据继续触发重新加载。
- content script 增加扩展上下文存活检查和同步异常捕获，降低重新加载扩展后出现 `Extension context invalidated` 的报错。
- 开发者模式重新加载扩展后，已经打开的旧网页仍建议刷新一次，让页面换成新版 content script。

## v1.2.0 变化

- 拖拽预览与最终保存拆开处理：预览优先复用网页已经渲染出来的内容，高清原图只在点击保存时获取。
- 页面图片允许读取像素时，直接生成约 240px 的本地 WebP 预览，不产生额外图片网络请求。
- 跨域图片无法读取像素时，尝试截取当前标签页中已经显示出来的图片区域作为预览，同样不重新请求高清图。
- 只有前两种预览方式都不可用时，才退回当前页面图片 URL。
- 保存阶段移除 `cache: no-store`，允许浏览器正常使用缓存。
- 保存前不再额外发送 HEAD 请求探测格式；真实格式由最终 GET 响应的 Blob 类型确定，减少一次网络请求。
- 收紧拖拽临时状态匹配：每次页面拖拽增加独立 `dragId`，旧拖拽数据无法仅凭“5 秒内发生过”混入下一次拖拽。
- Windows Chrome 的 `DataTransfer.files` 改为最低优先级，仅在 URL / HTML 拖拽数据均不可用时使用。
- 临时 File 必须满足 `size > 0` 且能真实解码为图片，避免空虚拟文件占据四格队列。
- “清空图片”会同时清除 Service Worker 中的拖拽临时状态。
- 预览加载失败时格子会明确显示提示，避免出现视觉为空、内部已占位的误判。

## 功能

- Chrome 侧边栏界面。
- 统一拖放区，自动填入下一个空位。
- 4 个指定格子，可直接拖到 1 / 2 / 3 / 4。
- 格子之间拖动交换顺序。
- 网页图片右键加入下一个空位或指定位置。
- 鞋款 `xxx` 与角度 `y` 自定义输入。
- 常用角度标签可添加、删除。
- 日期格式 `YYYYMMDD`。
- 文件名实时预览。
- 尝试从 `currentSrc`、`srcset`、懒加载属性、高清图属性、图片链接等位置记录高分辨率候选。
- 拖拽阶段使用轻量预览，保存阶段按设置选择高清原图。
- 重复图片提示。
- 根据最终图片响应类型自动识别 JPG、PNG、WEBP、AVIF 等扩展名。
- 保存完成后可自动清空图片、角度或鞋款。
- 队列、标签和设置保存在扩展本地存储中。
- 保存目录句柄保存在扩展 IndexedDB 中。

## 安装或升级

1. 解压发布 ZIP。
2. Chrome 地址栏打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目目录 `extensions/shoe-view-downloader`，或选择发布 ZIP 解压后的 `shoe-view-downloader` 文件夹。
6. 点击工具栏里的扩展图标打开侧边栏。

Edge Chromium 可在 `edge://extensions/` 中按相同方式加载。

从旧版升级时，可以用新版文件覆盖原扩展目录，再在扩展管理页面点击“重新加载”。扩展 ID 保持一致时，原有队列、标签、设置和已保存的目录句柄可以继续使用。

## 使用

1. 在“保存位置”点击“选择文件夹”。
2. 在系统文件夹选择器中指定目标目录。
3. 填写鞋款，例如 `D3119CM6`。
4. 填写角度，例如 `外侧`，也可以点击常用标签。
5. 从网页把图片拖入大拖放区，图片会依次进入 1 → 4。
6. 拖入时四格只显示轻量预览；高清候选地址会同时记录下来。
7. 需要调整时，把已填入的格子拖到另一个格子交换位置。
8. 点击“保存图片”，若高清 URL 已存在于来源标签页资源树中则直接复用；否则才正常获取高清原图并写入目标目录。

## 文件夹权限

扩展会把所选文件夹的 `FileSystemDirectoryHandle` 保存到 IndexedDB。重新打开浏览器后会尝试恢复该句柄。

Chrome 有时会要求重新确认文件夹写入权限。权限被撤销后，可以通过“更换文件夹”重新选择。

## 权限说明

- `sidePanel`：显示侧边栏。
- `storage`：保存队列、标签、设置和临时 UI 状态。
- `contextMenus`：为网页图片增加右键快捷入口。
- `debugger`：短暂连接来源标签页，通过 Chrome DevTools Protocol 读取该标签页已经加载完成的图片资源；每次读取结束立即 detach。
- `http://*/*` / `https://*/*`：读取网页图片元数据、获取最终原图，以及在跨域预览无法直接读取像素时截取当前活动标签页可见内容。

扩展不包含远程脚本，也没有图片上传逻辑。

## 已知边界

- Canvas / WebGL 绘制内容缺少真实图片 URL 时，无法保证获取到原始图片文件。
- 跨域图片的本地 Canvas 预览可能被浏览器安全策略阻止，此时会使用当前标签页截图裁切作为预览。
- 图片位于 iframe 内时，截图裁切坐标可能无法可靠换算；此时格子可能只显示“未生成本地预览”，高清原图地址仍会保留供保存阶段使用。
- 带复杂登录鉴权或一次性签名的高清地址可能失效。
- Blob 图片依赖原标签页临时转换，建议拖入后及时保存。
- 个别网站会拦截浏览器原生拖拽，此时可以使用图片右键菜单加入队列。
- 某些受系统保护的目录无法被 File System Access API 选作保存位置。
